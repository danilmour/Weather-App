# Portugal Weather

A 5-day weather forecast app for Portugal, built with React and Material UI. Weather data is provided by [IPMA](https://www.ipma.pt) (Instituto Português do Mar e da Atmosfera).

## Features

- Search and select Portuguese cities/districts
- 5-day forecast with temperature, precipitation, wind, and weather type icons
- Dark theme with smooth fade-in transitions
- Loading skeletons and error handling

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command            | Description          |
| ------------------ | -------------------- |
| `npm run dev`      | Start dev server     |
| `npm run build`    | Build for production |
| `npm run preview`  | Preview production build |

## Built With

- [Vite](https://vitejs.dev)
- [React](https://react.dev)
- [Material UI](https://mui.com)
- [IPMA Open Data API](https://api.ipma.pt)
